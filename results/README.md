# Results

This folder stores the outputs generated by the notebook after a full experiment run.

## Folder Structure

```
results/
├── tables/         ← CSV files with numerical results
└── figures/        ← PNG plots
```

## Tables (`results/tables/`)

| File | Description |
|---|---|
| `main_results.csv` | Per-experiment, per-model: Train RMSE, Test RMSE, Test MAE, Test R², Generalization Gap, Raw Features, Transformed Features |
| `cv_results.csv` | 5-fold cross-validation: CV RMSE mean and std per experiment/model |
| `feature_summary.csv` | Experiment ID, raw feature count, and type of added features |
| `redundancy_evidence.csv` | Pearson correlation between each original and its deliberately redundant counterpart |

## Figures (`results/figures/`)

| File | Description |
|---|---|
| `feature_count_vs_rmse.png` | Raw feature count vs Test RMSE — directly addresses the main research question |
| `configuration_vs_r2.png` | Feature configuration vs Test R² — shows explained variance per experiment |
| `train_vs_test_rmse.png` | Train RMSE vs Test RMSE side-by-side — shows generalization gap |
| `cv_rmse_comparison.png` | Cross-validation RMSE mean ± std — shows stability across folds |
| `redundancy_correlation.png` | Heatmap or bar chart of Pearson correlations for redundant features |

> **Note:** These files are generated when you run the notebook from top to bottom.
> They are not committed to the repository by default.
> Run the notebook to produce them.
