Place your presentation file here once it is ready.

## Suggested Contents

- `Team04_HousePrice_Presentation.pptx` — Final presentation slides

## Suggested Slide Structure

1. Title slide (team, course, academic year)
2. Research question and motivation
3. Hypotheses
4. Dataset overview
5. Experimental design (six configurations table)
6. Models and preprocessing
7. Results — main experiment (table + key plots)
8. Results — cross-validation
9. Analysis — does adding more features always help?
10. Hypothesis evaluation (supported / partially supported / not supported)
11. Limitations
12. Conclusion
13. References

> Keep the presentation consistent with the actual results in the notebook.
> Do not report conclusions that are not supported by the experimental evidence.
